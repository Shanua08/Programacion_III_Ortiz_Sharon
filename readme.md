📖 Descripción del Repositorio

Este repositorio contiene las prácticas, proyectos y código desarrollados durante la asignatura Programación III. El objetivo principal es dominar las tecnologías fundamentales del desarrollo web moderno, abarcando desde las bases del diseño frontend hasta arquitecturas backend escalables.

🚀 Tecnologías y Conceptos Clave

A continuación se resumen brevemente los conceptos principales abordados en el curso:

1. HTML (HyperText Markup Language)

Es el lenguaje de marcado estándar utilizado para definir la estructura y el contenido de un sitio web. A través de etiquetas semánticas, permite organizar elementos como textos, imágenes, enlaces, formularios y multimedia.

2. CSS (Cascading Style Sheets)

Es el lenguaje de estilos que se utiliza para describir la presentación visual de una página web escrita en HTML. Permite aplicar estilos, fuentes, colores, animaciones y diseñar interfaces adaptables a diferentes pantallas (Responsive Design).

3. JavaScript (JS)

Lenguaje de programación interpretado, dinámico y multiparadigma. Es el motor principal del desarrollo web que permite agregar interactividad, manipular el DOM en tiempo real, manejar peticiones asíncronas y lógica de negocio en el cliente o en el servidor (a través de Node.js).

4. TypeScript (TS)

Es un superset de JavaScript desarrollado por Microsoft que añade tipado estático opcional y características avanzadas de Programación Orientada a Objetos. Ayuda a detectar errores durante la fase de desarrollo, mejorando la mantenibilidad y escalabilidad del código.

5. ReactJS

Librería de JavaScript de código abierto desarrollada por Meta, enfocada en la creación de interfaces de usuario (UI) reactivas y eficientes. Se basa en una arquitectura de componentes reutilizables y utiliza un Virtual DOM para optimizar la renderización.

6. NestJS

Framework progresivo de Node.js para la construcción de aplicaciones backend eficientes, fiables y altamente escalables. Está construido con TypeScript y aprovecha conceptos de arquitectura modular, inyección de dependencias y patrones inspirados en Angular.
